# Docs

What stays in `Docs/` is what spans the whole project: the goal, the model specification,
methodology shared by several workstreams, the roadmap, references, and the development log.
Each workstream's plans, design notes and open questions live in `Research/<Workstream>/`
(see [`../Research/README.md`](../Research/README.md)). The open questions are aggregated in
[`../Research/ISSUES.md`](../Research/ISSUES.md).
